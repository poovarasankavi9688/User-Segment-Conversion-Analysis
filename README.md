🚀 **Power BI Project: Customer Funnel Analysis Dashboard**

I'm excited to share my latest Power BI project focused on **Customer Funnel Analysis**, where I analyzed user behavior across multiple stages of a conversion funnel to identify drop-offs and uncover opportunities for improving conversion rates.

### 📊 Project Highlights

* Cleaned and transformed event-level data using **Power Query**
* Removed duplicates and validated data types
* Created a **Stage Order** to maintain the correct funnel sequence
* Calculated **unique users** at each funnel stage using DAX
* Built **stage-to-stage conversion rate** measures
* Performed **drop-off analysis** to identify the stage with the highest user loss
* Implemented **automated flagging** for the biggest drop-off stage
* Compared **conversion rates across user segments**
* Added **business recommendations** based on funnel insights
* Designed an interactive executive dashboard with KPI cards and visualizations

### 📈 Dashboard Features

* KPI Cards (Total Users, Completed Users, Overall Conversion Rate, Biggest Drop-off)
* Funnel Chart
* Stage Conversion Table
* Drop-off Analysis Chart
* Segment Comparison
* Business Insights & Recommendations

### 💡 Key Business Insight

The analysis identified the stage with the highest user drop-off, helping highlight where users experience the most friction. This insight can guide product teams in optimizing the customer journey and improving overall conversion rates.
